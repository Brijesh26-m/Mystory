# Story Portfolio

> A cinematic, story-driven developer portfolio designed to turn a personal portfolio into an interactive digital experience.

![Portfolio Preview](./public/preview.png)

## Overview

This portfolio is not designed as a traditional resume website.

It is built as an interactive visual story where projects, skills, experience, and contact information are presented through motion, typography, transitions, and carefully designed interactions.

The goal is simple:

**Don't just show the work. Tell the story behind it.**

---

## ✨ Experience

The portfolio is structured around a visual storytelling journey:

### The Mind Behind The Build
An introduction to the person, mindset, and approach behind the work.

### Selected Work
A curated presentation of projects with visual storytelling and interactive transitions.

### Tools Of The Trade
A visual representation of the technologies and tools used to transform ideas into digital products.

### Start A Conversation
A final section designed to turn the experience into a real conversation.

---

## 🎨 Design Philosophy

The website follows a cinematic and minimal visual language.

Key principles:

- Dark, premium visual direction
- Large editorial typography
- Smooth scrolling
- Scroll-driven storytelling
- Meaningful motion
- Subtle glow and gradient effects
- Interactive project presentation
- Responsive layouts
- Mobile-first considerations
- Performance-aware animations

The interface is designed to feel more like an experience than a collection of webpages.
